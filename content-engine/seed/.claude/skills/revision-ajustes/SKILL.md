# Ajustes

1. Lee cada anotación y ubica a qué parte se refiere: copy, lámina concreta, template o enfoque.
2. Aplica cada anotación de forma literal. Si es ambigua, elige la lectura más conservadora.
3. No toques lo que no se pidió.
4. Verifica que el resultado sigue cumpliendo `copy-instagram` y `diseno-pieza`.
5. Si la anotación revela una regla general, escríbela en `learning` en una frase accionable. Si es un gusto puntual, deja `learning` vacío.
